# SwarmOracle 2.0 素材来源 / Asset credits

本项目的大多数视觉素材是为 SwarmOracle 2.0 制作的 **AI 生成像素画**。少量时间线标记 SVG 由项目手工绘制，用来提高界面可读性。这些原创素材可按项目许可证使用。

Most visual assets in this project are **AI-generated** pixel art, created specifically for SwarmOracle 2.0. A small set of in-repo timeline marker SVG icons is handcrafted for UI readability. They are original works and may be freely used under the project license.

## 应用素材的生成与许可 / App asset generation and license

**生成方式：** 位图素材由 AI 图像生成工具制作。既有 UI 与辩论竞技场的最近一批生成素材使用 Gemini image-preview 模型；有来源记录的 PNG 旁保留对应的 `.meta.json` 文件。时间线标记 SVG 在仓库中手工绘制。

**Generation:** Raster art assets were created using AI image generation tools. Latest generated UI and Debate Arena assets were produced with Gemini image-preview models, with per-file `.meta.json` provenance next to generated PNGs when available. Timeline marker SVGs were handcrafted in-repo.

**许可：** 上表中的 AI 生成素材和手工 SVG 遵循[项目许可证](../../../LICENSE)。随附的第三方字体使用独立许可证，见下文。

**License:** The AI-generated assets and handcrafted SVGs listed above follow the [project license](../../../LICENSE). Bundled third-party fonts are licensed separately; see below.
