这些变量分别控制什么？What do these variables control?

以下解释对应这组历史实验。具体配置请核对当前版本文档。These explanations describe the archived experiment. Check the current documentation before configuring a new run.

模型温度 Temperature

temperature 影响模型如何解释相同的分歧线索。旧样本没有显示简单的“越高越会分叉”关系。

temperature affects how the model interprets the same disagreement signals. The samples did not show a simple rule that higher values produce more forks.

分叉灵敏度 Branch sensitivity

branch_sensitivity 是提示词中的判断提示，需要结合提示词和温度一起看。

branch_sensitivity is a cue in the prompt. Read it together with the prompt wording and temperature.

提示词版本 Prompt variant

fork_prompt_variant 决定模型把哪些分歧视为分叉理由。A 是基线；B 组合了多个条件；C 和 D 分别强调互斥走向与制度分歧。

fork_prompt_variant defines which disagreements justify a fork. A is the baseline, B combines several conditions, and C and D emphasize mutually exclusive paths and institutional disagreement.

分叉检查名额 Fork-check limit

fork_detector_active_branch_limit 限制每轮接受分叉检查的活跃分支数。旧实验中，k=0 不加这个限制，k=1 只检查优先级最高的一条。

fork_detector_active_branch_limit limits how many active branches receive fork checks each round. In this experiment, k=0 adds no limit and k=1 checks only the highest-priority branch.

轮数 Rounds

轮数决定有多少次机会继续分叉。比较两个设置时，需要先固定轮数。

The number of rounds determines how many opportunities remain to branch. Hold it fixed when comparing two settings.

分叉前提 Fork prerequisites

这组实验要求存在分歧信号、尚未到最后一轮，并且活跃分支数没有达到系统上限。

These experiments required disagreement signals, at least one remaining round, and room below the system’s active-branch limit.

    先固定比较条件Hold the conditions fixed

    对照提示词时，保持同一问题、模型、温度、灵敏度和轮数。否则无法把差异归到一个变量上。

    To compare prompts, keep the question, model, temperature, sensitivity, and round count fixed. Otherwise the difference cannot be attributed to one variable.

    另外测试数量限制Test branch limits separately

    这份档案中的数量限制减少了分支，但新模型和新问题仍需要重新测试。

    The limits reduced branch counts in these records. New models and questions still need a fresh test.

    同时读故事质量Read the story quality too

    分支更多，不代表理由更可信。还要检查每条走向是否有实质差异，是否有发言和行动支持。

    More branches do not make the reasoning more credible. Check whether the paths differ in substance and whether messages and actions support them.
