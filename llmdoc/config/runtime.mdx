# 运行时配置 / Runtime Configuration

`backend/app/config.py` 定义类型、默认值和校验器。`.env.example` 是本地模板，`.env.docker.example` 是 Compose 模板。不要在文档、日志、replay、snapshot 或测试工件中记录真实密钥。字段范围直接查 `config.py`。

`backend/app/config.py` defines types, defaults, and validators. `.env.example` is the local template and `.env.docker.example` is the Compose template. Never place real secrets in documentation, logs, replays, snapshots, or test artifacts. Consult `config.py` for exact field ranges.

## 公开默认 LLM 哨兵 / Public Default LLM Sentinel

根目录 `.env.example` 默认 `LLM_RESPONSES_URL=http://127.0.0.1:8317/v1`，`LLM_API_KEY` 为占位值，`LLM_MODEL_NAME=gpt-5.4-mini`。该 loopback 与占位 key 组合只保证应用和官方样例能启动，不证明存在可用 LLM。实际部署把模板复制为 `backend/.env` 后再改。

The root `.env.example` defaults to `LLM_RESPONSES_URL=http://127.0.0.1:8317/v1`, a placeholder `LLM_API_KEY`, and `LLM_MODEL_NAME=gpt-5.4-mini`. That loopback and placeholder-key combination only lets the application and official samples start; it does not prove that an LLM is available. A real deployment copies the template to `backend/.env` and then changes it.

## BYOK URL / BYOK URL Rules

请求可覆盖 `llm_api_key`、`llm_base_url`、`llm_model`、RPM 和 TPM，只影响当前请求。

- 远端显式传 base URL 时必须同时传 API key；精确本地 provider 可免 key。
- scheme 只允许 `http/https`。官方托管 host 必须 `https`。
- 精确本地 host 只包括 `localhost`、`127.0.0.1`、`0.0.0.0`、`host.docker.internal` 和 `::1`。
- `http` 只允许已启用的精确本地 host，或显式 allowlist 且启用 private-host 选项的 self-hosted 边界。
- URL userinfo、params、query 和 fragment 一律拒绝。
- 精确本地 URL 未提供 key 时不发送 `Authorization`，也不会回退泄露服务端默认 key。
- request-scoped RPM/TPM 为 `0` 时，不增加该请求层限流。

RPM、TPM、并发和 pending 是独立限流层。对应层设为 `0` 关闭该层；`LLM_CONCURRENCY=0` 还会关闭由它派生的 purpose-lane semaphore。

Requests may override `llm_api_key`, `llm_base_url`, `llm_model`, RPM, and TPM for that request only. A remote explicit base URL requires an API key, while exact local providers may omit it. Only `http` and `https` are allowed, and official hosted endpoints require HTTPS. The exact local host set is `localhost`, `127.0.0.1`, `0.0.0.0`, `host.docker.internal`, and `::1`. Plain HTTP is limited to enabled exact-local hosts or explicitly allowlisted private self-hosted boundaries. Userinfo, params, queries, and fragments are rejected. A keyless exact-local request sends no Authorization header and never falls back to the server default key. A request-scoped RPM or TPM value of zero disables only that request layer. RPM, TPM, concurrency, and pending limits are independent; zero disables the corresponding layer, and `LLM_CONCURRENCY=0` also disables its derived purpose-lane semaphore.

## 推理强度 / Reasoning Effort

一次模型调用的有效 reasoning effort 按 **已绑定 run/operation scope → 本次调用选择 → 服务端默认** 解析。调用未指定时继承外层 scope；显式清除 scope 后，仍可由本次调用或服务端默认决定。内部辅助步骤、流支持探针和 fallback 不得用自己的固定值覆盖已绑定策略。

`none` 是一个明确选择：请求构造不发送 reasoning 字段，并阻断其它阶段把自己的默认 effort 注入本次调用；它只描述本应用发送的 payload，不能据此声称上游模型没有内部推理。

The effective reasoning effort is resolved in this order: bound run or operation scope, this call's choice, then the server default. An unspecified call inherits its outer scope; after an explicit scope clear, the call or server default may decide. Internal helpers, streaming probes, and fallbacks cannot replace a bound policy with their own fixed value. `none` is an explicit choice: the request omits a reasoning field and prevents later phases from injecting their own default. It describes only the payload sent by this application and says nothing about whether the upstream model reasons internally.

## 服务与安全 / Service and Security

- 默认 `HOST=127.0.0.1`、`PORT=18927`；frontend dev/Compose 为 `127.0.0.1:18928`。
- file-backed SQLite 使用 WAL 与 `busy_timeout=5000`。内存 SQLite 跳过 WAL。
- `SESSION_SECRET` 空值关闭本地 session gate；非空启用 REST 与 WS 认证。
- `ADMIN_TOKEN` 保护 `/api/admin/*` 与 `/metrics`。
- `ENV=production/prod` 启用启动 fail-fast，程序检查 `SESSION_SECRET` 和 `ADMIN_TOKEN` 非空；生成独立、唯一密钥是部署者义务。admin LLM test 的本地 URL 拒绝条件当前是精确 `ENV=production`，不能推定 `prod` 在该入口有相同效果。
- `EXPOSE_API_DOCS` 默认 false。
- Model profile 的 key 以本地 SQLite 明文保存，适用于单用户 self-hosted；密钥字段仅返回 `has_api_key`。key、Base URL 与 model 是一个 provider 绑定。

- The default backend address is `127.0.0.1:18927`; frontend development and Compose use `127.0.0.1:18928`.
- File-backed SQLite uses WAL and `busy_timeout=5000`; in-memory SQLite skips WAL.
- An empty `SESSION_SECRET` disables the local session gate; a non-empty value enables REST and WebSocket authentication.
- `ADMIN_TOKEN` protects `/api/admin/*` and `/metrics`.
- `ENV=production` or `prod` enables startup fail-fast checks for non-empty session and admin secrets. Operators must generate distinct unique secrets. The admin LLM-test endpoint currently applies its local-URL rejection only to exact `ENV=production`; do not assume `prod` has the same endpoint behavior.
- `EXPOSE_API_DOCS` defaults to false.
- Model-profile keys are stored as plaintext in local SQLite for single-user self-hosting. Responses expose only `has_api_key`. Key, base URL, and model form one provider binding.

## 搜索与功能开关 / Search and Feature Flags

- `ENABLE_WEB_SEARCH` 默认 opt-in。搜索失败必须 fail-soft，不能阻断 simulation。
- 模型原生搜索不由 `WEB_SEARCH_PROVIDER=native` 开启；取决于 Responses provider、profile capability 和 native upstream 声明。
- 后端 gate 关闭通常返回 404；前端通过 `/api/capabilities` 隐藏或禁用入口。
- `FEATURE_MEMORY_PROMOTION` 默认 false，且须与 `FEATURE_AGENT_IDENTITY=true` 同时满足才启用 v1 writer/reader。它没有 capability key、REST 激活面或 UI，也未写入公开 env 模板。改回 false 是非破坏回滚：reader 忽略 v1，物理记录不删除。
- 修改功能开关后重启 backend。

- `ENABLE_WEB_SEARCH` is opt-in. Search failures are fail-soft and cannot block a simulation.
- Native model search is not enabled by `WEB_SEARCH_PROVIDER=native`; it depends on the Responses provider, profile capability, and an upstream native-search declaration.
- A disabled backend gate usually returns 404, while the frontend hides or disables the entry through `/api/capabilities`.
- `FEATURE_MEMORY_PROMOTION` defaults to false and also requires `FEATURE_AGENT_IDENTITY=true` before its v1 reader and writer operate. It has no capability key, REST activation surface, UI, or public environment-template entry. Returning it to false is a non-destructive rollback: the reader ignores v1 records without deleting them.
- Restart the backend after changing feature flags.
