# SwarmOracle 使用指南

这份指南带你走完一次完整的推演，并介绍每种玩法怎么用。第一次使用前，请先按 [README](../README.md) 配好 LLM 并启动前后端（本地开发：后端 `18927`、前端 `18928`，浏览器只需打开 `http://localhost:18928`）。

> 小提示：本地开发时，**后端必须先在 18927 跑起来**，否则前端会一直转圈或报错。

---

## 第一次推演：3 步上手

1. 在首页输入框写一个「如果……会怎样？」的问题，例如「如果诸葛亮多活 10 年？」。也可以直接点下方「快速开始」里的模板，会自动填好问题和相关角色。
2. （可选）拖动 **推演轮数** 和 **Agent 数量** 两个滑块。轮数越多、角色越多，结局越细，但等待也越久。首页会实时估算耗时。
3. 点 **⚡ 开始推演**，等待推演完成后点 **查看结果 →**。

推演过程中你会看到：左侧的 **Agent 列表**（每个角色有头像、身份、立场、情绪），中间的 **分支树**（不同走向的世界线，带概率），右侧的 **实时发言**（角色逐轮发言，并会互相引用、回应彼此）。

---

## 结果页能做什么

推演结束后进入结果页，你会看到：

- **预测结论**：一句话直接回答你的原问题，并给出置信度（高/中/低）。它不是复述问题，而是给结论，并会坦白哪些地方还不确定。
- **概率采样**：各个结局出现的可能性分布。
- **每条世界线（结局）卡片**：标题、概率、以及「对此问题的回答」——具体到谁做了什么、导致什么结果。

结局卡片下方会按当前数据展示这些入口：
- **阅读完整故事** — 这条世界线有完整叙事时，可展开查看。
- **进入会客厅** — 进入神谕密室，向这条线的参与者追问（见下文「神谕密室」）。
- **只改一步** — 进入一间聚焦「最关键的那一步」的神谕密室，专门讨论这条结局的转折点。
- **其他世界线** — 有多条结局时，可横向浏览、对照其他结局的走向。

结果页顶部还能 **导出 Markdown、生成分享文案、复制固定链接、查看因果图谱**。下方的参与者区域还提供「反事实对比」入口（见下文）。

## 六种玩法

### 1. 多分支推演（核心）
就是上面的主流程。一个问题分裂成多条世界线，每条都有完整的角色推演和结局。**默认开启，无需配置。**

### 2. 辩论竞技场
在首页输入问题后点 **进入辩论竞技场**。AI 会生成正方、反方、评委三种角色，分 5 个阶段（开篇 / 交锋 / 反驳 / 总结 / 裁决）展开辩论，并实时显示局势条和评委倾向。适合快速看清一个争议的两面和胜负判词。**默认开启。**
- 想看「论点地图」（把辩论拆成论证结构）需要开启 `FEATURE_ARGUMENT_MAP`（本仓库模板默认已开）。

### 3. 神谕密室
在结果页某条结局卡片点 **进入会客厅**，选 1–3 位当前世界线的参与者进入。你可以向他们追问，角色会**带着自己的人物设定和这条世界线里发生过的事**来回答，由「档案官」主持、点名最相关的角色回应。适合深挖「为什么会这样」「他当时怎么想」。**默认开启。**

### 4. 世界线圆桌
多条结局可用时，结果页会显示 **开始圆桌**。多条世界线的代表围坐讨论，你可以选讨论形式和参会阵容，看他们综合不同立场得出结论。**默认开启；单结局结果页不显示圆桌入口。**
- 圆桌的 **Deep Dive** 工作台（与单个代表私聊 / 多代表问卷 / 研究分析师）属于进阶功能，分别需要 `FEATURE_AGENT_CONVERSATION` / `FEATURE_ROUNDTABLE_SURVEY` / `FEATURE_ROUNDTABLE_ANALYST`（默认关闭，需要时在配置里打开）。

### 5. 反事实对比
在结果页下方的参与者区域找到「反事实」入口，挑一条某个角色在某一轮**真实说过**的话，把它改写成别的内容。系统会据此**新建一条反事实世界线并重新推演**，完成后点「对比分支 →」进入对比页，用红绿高亮逐条标出新旧世界线的差异。适合验证「如果当时换个说法，结局会不会变」。**默认开启**（`FEATURE_COUNTERFACTUAL_REPLAY`）。

> 注意：结局卡片上的 **只改一步** 是神谕密室的一个变体（聚焦转折点讨论），不会重新推演；真正会重新推演的是这里说的「反事实对比」。

### 6. 因果图谱
在结果页点 **查看因果图谱**，用有向图看清事件之间「谁触发了谁」。可以用页内下拉框筛选单条分支或看全部。需要 `FEATURE_CAUSAL_GRAPH`（本仓库模板默认已开）。
- 相关的 **阵营关系** 视图需要 `FEATURE_FACTIONS`（默认已开）。

## 搜索增强推演（可选）

首页有 **搜索增强推演** 开关。打开后，系统会在推演前自动联网搜索相关资料并注入到角色的提示里，让推演更贴近现实信息。这需要在配置里开启 `ENABLE_WEB_SEARCH` 并填好搜索服务商，详见 [CONFIGURATION.md](./CONFIGURATION.md)。推荐路径不需要你理解 provider、API key 这些细节，按提示开启即可。

---

## 中英文切换

界面右下角有 **EN / 中文** 切换按钮，全站文案会即时切换。角色的发言会跟随你提问时使用的语言。

## 常见疑问

- **点了开始推演没反应？** 确认问题输入框不为空，且本地开发时后端已在 18927 运行。
- **看不到「因果图谱 / 论点地图」入口？** 这些是开关控制的功能，确认对应 `FEATURE_*` 已设为 `true`（本仓库 `.env.example` / `.env.docker` 默认已开核心几项），详见 [CONFIGURATION.md](./CONFIGURATION.md)。
- **结果页「预测结论」显示「暂无预测结论」？** 说明这次没能生成确定结论，属于正常的兜底，原问题仍会保留展示。
- **推演到最后停在「叙事生成」很久？** 分支较多时，系统会逐条生成结局故事，稍等即可，不是卡死。
- **AI 的预测能当真吗？** 不能。SwarmOracle 仅供娱乐和启发，请勿用于真实的金融、医疗或法律决策。
