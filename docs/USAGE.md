# SwarmOracle 使用指南

这份指南带你走完一次完整的推演，并介绍每种玩法怎么用。第一次使用前，请先按 [README](../README.md) 配好 LLM 并启动前后端（本地开发：后端 `18927`、前端 `18928`，浏览器只需打开 `http://localhost:18928`）。

> 小提示：本地开发时，**后端必须先在 18927 跑起来**，否则前端会一直转圈或报错。

---

## 第一次推演：3 步上手

1. 在首页输入框写一个「如果……会怎样？」的问题，例如「如果诸葛亮多活 10 年？」。也可以直接点下方「快速开始」里的模板，会自动填好问题和相关角色。
2. （可选）拖动 **推演轮数** 和 **Agent 数量** 两个滑块。轮数越多、角色越多，结局越细，但等待也越久。首页会实时估算耗时。
3. 点 **⚡ 开始推演**，等待推演完成后点 **查看结果 →**。

推演过程中你会看到：左侧的 **Agent 列表**（每个角色有头像、身份、立场、情绪），中间的 **分支树**（不同走向的世界线，带概率），右侧的 **实时发言**（角色逐轮发言，并会互相引用、回应彼此）。

---

## 结果页能做什么

推演结束后进入结果页，你会看到：

- **预测结论**：一句话直接回答你的原问题，并给出置信度。它不是复述问题，而是给结论，并会说明哪些地方还不确定。
- **世界线卡片**：每条结局都有标题、概率、故事和「对此问题的回答」。
- **下一步入口**：结果页会按数据和功能开关显示会客厅、圆桌、分支对比、图谱工作台、知识图谱浏览器、时间线星系、Agent 追问等入口。

结局卡片下方常见按钮：

- **阅读完整故事** — 展开这条世界线的完整叙事。
- **进入会客厅** — 选 1–3 位当前世界线参与者，进入神谕密室追问。
- **只改一步** — 进入聚焦关键转折点的会客厅，不会重新跑主推演。
- **其他世界线** — 多结局时打开异线画廊，对照另一条世界线的摘要。

结果页顶部还能 **导出 Markdown、生成分享文案、复制固定链接、导出 snapshot、查看因果图谱、打开图谱工作台、查看排行榜**。页面下方的 **下一步 / What's Next** 卡片会继续提供分支对比、图谱工作台、知识图谱浏览器 / Knowledge Graph Explorer、时间线星系 / Timeline Galaxy、Agent 追问和分享入口。

## 六种玩法

### 1. 多分支推演
在首页输入问题，点 **⚡ 开始推演**。一个问题会分裂成多条世界线，每条都有角色发言、概率和结局。高级设置里可以切换输入整理方式（黑板 / 原文）、显示方式（经典 / 像素剧场）、推理强度和推演模式（谨慎 / 均衡 / 探索）。

### 2. 辩论竞技场
在首页输入问题后点 **进入辩论竞技场**。系统会创建正方、反方和评委，按阶段推进辩论。结果页可以点 **加载图谱 / Load map**，把主张、证据、反驳和裁决连起来看。

### 3. 神谕密室
在结果页某条结局卡片点 **进入会客厅**，选择当前世界线里的参与者追问。角色会带着这条线里已经发生的事来回答，适合问「为什么会这样」「当时怎么想」。

### 4. 世界线圆桌
多条结局可用时，结果页会显示 **开始圆桌**。你可以选圆桌形式（深度剖析 / 快速过审 / 交锋模式）和参会代表，让不同世界线的代表一起讨论。单结局结果页不会显示圆桌入口。

圆桌完成后会出现 **Deep Dive** 工作台，里面有三个页签：**1 对 1 访谈**、**研究分析师**、**交叉质询**。这三项现在默认可用；如果服务器关闭对应功能，页面会显示不可用提示。之后再打开同一个已完成圆桌时，页面会载入保存好的讨论结果和 Deep Dive，不会重新从选代表开始。

### 5. 反事实对比
在结果页切到图谱工作台或参与者分析区，找到反事实入口，选某个 Agent 在某一轮真实说过的话并改写。系统会创建一条新的反事实世界线，完成后可进入 **对比分支**，横向看新旧世界线哪里开始不同。

### 6. 因果图谱与知识图谱
结果页点 **查看因果图谱** 可以看事件之间「谁触发了谁」。点 **图谱工作台** 可以在 **Causal / Split / Knowledge Graph** 之间切换；窄屏上 Split 会自动收成单图视图，图谱页会保留缩放、搜索或移动端导航提示。`FEATURE_KG_EXPLORER` 开启时，结果页的 **下一步 / What's Next** 还会显示 **知识图谱浏览器 / Knowledge Graph Explorer** 和 **时间线星系 / Timeline Galaxy** 两张卡片，用来继续筛选节点、查看详情和发起节点追问。

## 默认可见的进阶功能

- **自定义 Agent 工坊**：首页右上角点 **Agents**，进入 Agent 库后可以创建、编辑、收藏、导出或从备份导入 Agent。创建好的自定义 Agent 可以加入推演或辩论。
- **教学模板**：首页点 **使用模板**，选择模板后会自动填入问题、推荐轮数和 Agent 数量。
- **预测日志**：打开 `/me/journal`，记录自己的预测概率，等结果出现后标记是否发生，查看校准情况。
- **Snapshot 导入 / 导出**：首页可以导入 snapshot ZIP；结果页可以导出当前 scenario snapshot。
- **Replay Trace**：打开 `/replay/:id`，查看反事实、续跑等 replay 分支的来源轨迹。

---

## 其他入口

- `/history`：查看过去的推演，按状态筛选，继续打开结果或删除本地场景。
- `/leaderboard`：查看预测排行榜，可按场景类型、日期和 Agent 数筛选。
- `/agents`：管理自定义 Agent、人物档案和备份。
- `/me/journal`：记录和复盘自己的预测。

---

## 搜索增强推演（可选）

首页有 **搜索增强推演** 开关。打开后，系统会在推演前自动联网搜索相关资料并注入到角色的提示里，让推演更贴近现实信息。这需要在配置里开启 `ENABLE_WEB_SEARCH` 并填好搜索服务商，详见 [CONFIGURATION.md](./CONFIGURATION.md)。推荐路径不需要你理解 provider、API key 这些细节，按提示开启即可。

界面右下角有 **EN / 中文** 切换按钮，全站文案会即时切换。角色的发言会跟随你提问时使用的语言。

## 常见疑问

- **点了开始推演没反应？** 确认问题输入框不为空，且本地开发时后端已在 18927 运行。
- **看不到「因果图谱 / 论点地图 / Deep Dive / 知识图谱浏览器 / 时间线星系」入口？** 这些入口由 `/api/capabilities` 控制；本仓库模板默认已开。若你改过 `.env`，确认对应 `FEATURE_*` 为 `true`，并重启后端。
- **结果页「预测结论」显示「暂无预测结论」？** 说明这次没能生成确定结论，属于正常的兜底，原问题仍会保留展示。
- **推演到最后停在「叙事生成」很久？** 分支较多时，系统会逐条生成结局故事，稍等即可，不是卡死。
- **AI 的预测能当真吗？** 不能。SwarmOracle 仅供娱乐和启发，请勿用于真实的金融、医疗或法律决策。
