如何运作

三步：提问 → 推演 → 结果

一条主链路：写下一个「如果……会怎样？」，AI 代理群体替你推演多条世界线，最后得到回答原问题的结果与分享卡片。

  1. 提出一个「如果……会怎样？」问题

    在首页输入框写下假设问题（如「如果诸葛亮多活10年？」），用滑块调推演轮数和 Agent 数量（默认各 5），点「开始推演」并确认。

  2. AI 代理群体实时推演多条世界线

    进入推演页后默认经典视图：顶部显示问题和「推演中」，分支树、Agent 面板和时间线随每轮实时更新，遇到分歧点自动分叉出新世界线。

  3. 得到回答原问题的结果与分享卡片

    推演完成后点「查看结果」，结果页用一句话回答原问题并给出置信度，每条世界线带标题、概率和故事摘要，可复制链接或导出 1200×630 预测卡片。

开箱即用：核心推演与多数功能（结果结论、因果图谱、知识图谱、反事实对比、辩论、圆桌）默认开启；只有「搜索增强」需自行配置搜索 provider。

前置条件：需要一个 OpenAI 兼容的 LLM 接口（在 .env 配置，或在首页高级设置里临时填入自己的 key）。

本地运行步骤

以上是本地运行步骤；本介绍页是静态页，不连后端。命令逐字保留；sk-… 仅占位，请勿在页面填入真实密钥。

docker-compose
docker compose up --build -d

先编辑 .env.docker 填入 LLM_RESPONSES_URL / LLM_API_KEY / LLM_MODEL_NAME，再运行命令。

Backend
cd backend
python -m venv .venv && source .venv/bin/activate
pip install -e ".[dev]"
cp ../.env.example .env
uvicorn app.main:app --host 127.0.0.1 --port 18927 --reload
Frontend
cd ../frontend
npm install
npm run dev

提示：前端需要在项目根目录新开第二个终端运行（Windows PowerShell 用户请参考 README）。
